What it does

The same building blocks as the paid tools, running for free in a browser tab.

Auto clip-finding

Ranks moments by hook strength — trigger words, exclamations, pacing shifts, dramatic pauses.

Vertical reframing

Center-crops to 9:16 automatically, ready for TikTok, Shorts and Reels.

Burned-in captions

Short, bold caption lines with a highlighted keyword, timed to speech.

Score + reason tags

Every candidate shows why it was picked, so you're not guessing.

Paste-link input

Drop a direct video URL instead of uploading a file, just like the paid tools.

Trim & re-export

Nudge a clip's start and end before export without leaving the browser.

Where this differs from the paid tools

Scoring is a transparent heuristic, not a large model judging "virality" — a good first pass, not a guarantee. The link field works with direct, publicly-hosted video files (.mp4/.webm); pulling from YouTube, Vimeo, Drive etc. needs a backend with API access to those platforms, which isn't included in this free version.
